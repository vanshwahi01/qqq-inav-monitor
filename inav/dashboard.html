Methodology

  • Holdings: daily from Invesco's public holdings feed (units per position, cash, futures).
  • Prices: raw (unadjusted) daily closes from Yahoo Finance; gaps are carried forward and flagged.
  • iNAV = (Σ units × close + cash) / shares outstanding. Index futures and their synthetic-cash offset cancel, so both are excluded.
  • Shares outstanding: manual override, else total value / official NAV on the holdings date, else Yahoo's figure if it agrees with the implied value, else implied from the holdings-date close (assumes ~0 premium that day).
  • Limitations: end-of-day only (real iNAVs publish every 15 seconds); holdings lag the valuation date; accrued dividends and fees are not modelled, so ex-dividend dates show as small jumps.
